# עדכונים לגרסה המותאמת

הגרסה הזו אינה משתמשת בערוץ העדכונים של upstream. חסימת macOS הישנה כבר מנעה החלפת מנועי הקול, אך דיווחה `none`, והממשק הציג זאת כאילו בוצעה בדיקה והגרסה מעודכנת. כעת התשובה היא `disabled`, הכפתור מציג ״עדכון ידני״, ואין טענה שנבדקה גרסה חדשה.

רישום תוסף העדכון וכתובות/מפתח updater הוסרו מהתצורה הפעילה בכל הפלטפורמות. בקשת check או install מחזירה disabled ואינה מורידה קובץ. הפניות העזרה של הגרסה המותאמת משתמשות ב־fork. זהות האפליקציה וההרשאות המותקנות לא שונו.

ערוץ חתום משלנו עדיין לא פעיל. לפני הפעלתו נדרש PR המשלים זהות חתימה, מפתח updater ציבורי תואם, manifest של ה־fork, בדיקת אימות/כשל חתימה ותרגיל עדכון/rollback בעותק ניסוי. לא נוצרו מפתחות חדשים ולא פורסם release. workflows של release/feed חסומים כברירת מחדל דרך `ROAMIES_SIGNED_RELEASES`; שינוי המשתנה לבדו אינו משלים את הכנת הערוץ ואין להפעילו לפני ה־PR הזה.

אימות: בדיקת רגרסיה לממשק מאמתת שגם תוצאת ״מעודכן״ ישנה אינה גוברת על disabled. בדיקת חוזה מאמתת שאין endpoints או רישום תוסף. typecheck/build, בדיקות prompt ו־10 בדיקות Rust עברו. עותק Preview חתום עם sidecar בדיקה שלח ל־Rust בקשות check וגם install; שתיהן החזירו disabled ללא החלפת האפליקציה. זו בדיקת הפרוטוקול המובנה, ללא התקנה על אפליקציית המשתמש. בדיקה חזותית של הכפתור עדיין ממתינה לפתיחת נעילת המק.
