# אינדקס ASM מקומי מתעדכן

`AsmIndexService` פותח את שלושת מקורות ASM לקריאה בלבד וללא מעקב אחר symlink
בכל חיפוש. הוא משווה inode, device, גודל, mtime ו־ctime ברזולוציית ננו־שניות.
רק שינוי במקורות גורם לקריאה ופענוח מחדש; חיפושים מקבילים חולקים רענון אחד.
מונחי החיפוש וסיווג אישי/חברה מחושבים פעם אחת לכל גרסת רשומה.

שינוי ב־`lifecycle.jsonl` מבטל את ה־cache. מחיקה, מקור גדול מדי, החלפה בזמן קריאה,
JSON פגום באינדקס או ביומן lifecycle, וכשל הרשאה אינם מחזירים תוצאות ישנות.
הכלי מחזיר שגיאה, ומסך העבודה מנקה את התוצאות הקודמות ומציג אותה.
היעדר ASM בהפעלה הראשונה מחזיר רשימה ריקה; היעלמות מקורות שכבר נקראו היא שגיאה.
החיפוש נשאר metadata בלבד, עם אותן מגבלות פלט, הסתרת סודות והפרדת אישי/חברה.

ב־14/11/2026 נמדדו שש קריאות לכל מימוש מול קובצי ASM האמיתיים, באותו תהליך Node
ואותה שאילתה. לפני: 872ms בטעינה ראשונה ו־833–911ms בקריאות הבאות. אחרי:
1050ms בטעינה ראשונה ו־4.9–7.7ms בקריאות הבאות. מזהי שתי התוצאות זהים.
זו מדידה מקומית של שאילתה אחת, לא benchmark כללי ולא מדידת טוקנים או עלות מודל.

בדיקות כוללות שינוי lifecycle ו־restore, החלפה אטומית עם גודל ו־mtime זהים,
symlink לאחר חימום cache, מקור שנעלם, פענוח שנכשל והתאוששות, וריקון תוצאות
ב־WorkspaceController כשיש שגיאה. אין כתיבה לקובצי ASM מתוך רכיב זה.

באותו תאריך בוצעה גם בדיקת ChatGPT דרך ה־sidecar החתום של Preview: שתי קריאות
`asm_recall` אמיתיות למקורות המקומיים הסתיימו בלי שגיאת כלי. האפליקציה הרגילה
והמקורות עצמם לא שונו.
