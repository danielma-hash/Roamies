# הקשר הפרויקט בסשני Claude מנוהלים

בפתיחת סשן או בהמשך סשן שנעצר, Jarvis טוען במפורש את `AGENTS.md`, `CLAUDE.md` ו־`.claude/CLAUDE.md` משורש ה־Git הקרוב ועד תיקיית העבודה, לפי הסדר. `.git` של worktree נתמך; אין קריאה של היעד שאליו הוא מפנה. בתיקייה ללא Git, רק התיקייה שנבחרה היא תחום הטעינה. הוראות בתיקיות עמוקות יותר נקראות על ידי Claude דרך כלי Read המאושר לפני עריכה בהן.

הטעינה עוברת דרך מדיניות הקריאה, מוגבלת ל־32 KiB לקובץ, 64 KiB בסך הכול ו־24 מקורות, ומקבלת UTF-8 בלבד. קובץ שאינו רגיל, קישור קובץ או קישור תיקייה שחורג מהפרויקט, מקור שנכשל בקריאה או שינוי במהלך הקריאה עוצרים את פתיחת הסשן. הוראות אינן נחתכות בשקט. היעדר קובץ הוראות אינו שגיאה.

הסשן ורשומת ההתקדמות שומרים שמות מקורות, גודל, SHA-256, שורש ותאריך טעינה; גוף ההוראות אינו נוסף ליומן Jarvis. Claude מקבל אותו ב־system append ולכן הוא יכול להיכלל בהיסטוריה שמנהל Claude. עדכון הוראות בזמן שהסשן פועל נכנס לתוקף לאחר עצירה והמשך מפורש. `snapshot: false` מונע שימוש ב־append ישן בהמשך שיחה; שינוי הקשר עשוי לפגוע ב־prompt caching.

`settingSources: []`, רשימת הכלים המפורשת, `strictMcpConfig` ובדיקות ההרשאה נשמרים. אין טעינה אוטומטית של הגדרות משתמש, hooks, MCP, הוראות שמעל שורש הפרויקט או `@imports`. הוראות הפרויקט אינן הרשאה ל־merge, deploy או שליחה. חיבור ASM מאושר לסשן הוא שינוי נפרד; זה עדיין אינו תהליך מפעל מלא.

אימות: 197 בדיקות TypeScript עברו, 4 בדיקות Docker ייעודיות דולגו; typecheck ו־build עברו. בסשן Claude אמיתי בפרויקט בדיקה, הסוכן ענה לפי קוד ייחודי בהוראות, ובהמשך אותו סשן ענה לפי הקוד המעודכן; hash המקורות השתנה ונשמר ביומן. hook בדיקה מקומי לא הופעל. אין שינוי UI ב־PR הזה, ואין כאן טענה לבדיקת מיקרופון או להתקנה ביישום הראשי.
