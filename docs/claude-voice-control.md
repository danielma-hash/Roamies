# שליטה קולית בסשני Claude

הפעל ב־הגדרות → התנהגות את האפשרות לעריכת קבצים ופקודות. נדרשת התקנה מחוברת של Claude Code המקומי; החשבון של ג׳ארוויס יכול להישאר ChatGPT.

- ״פתח סשן Claude חדש בפרויקט Roamies בשם בדיקת התחברות. תבקש ממנו לבדוק את הטסטים בלי לשנות קוד.״

- ״מה המצב של בדיקת התחברות, ומה הייתה התשובה האחרונה?״
- ״עצור את הסשן בדיקת התחברות.״
- ״המשך את הסשן בדיקת התחברות ובקש ממנו לסכם מה נשאר.״

בפתיחה יש לזהות את תיקיית הפרויקט המלאה. כשיש כמה שיחות בשם דומה, יש לבחור את השיחה המדויקת. לפני פתיחה או שליחת הוראה מוצגים שם השיחה, הפרויקט ותוכן ההוראה לאישור; אפשר לענות ״כן״ או ״לא״. גם כתיבה לקבצים והרצת פקודות בתוך Claude דורשות אישור ועוברות את כללי הבטיחות של Roamies.

## משמעות הפעולות

- **שליחה לסשן פעיל:** ההוראה מצטרפת לתור של אותו תהליך. היא מתחילה אחרי ההוראה הנוכחית. ״התקבלה״ אינה אומרת שהמשימה הסתיימה.
- **עצירה:** סוגרת את תהליך Claude המנוהל ומבטלת את ההוראות שממתינות בתור. אינה מוחקת היסטוריה ואינה מבטלת שינויים שכבר נעשו בקבצים. זמינה גם כשפעולות הושבתו, כדי שאפשר יהיה לעצור עבודה קיימת.
- **המשך:** ממשיך באותו מזהה ובהיסטוריה הקיימת. אינו יוצר fork.
- **סגירת Roamies:** סוגרת את התהליכים שהיא מנהלת. לאחר פתיחה מחדש בחר את השיחה בהיסטוריה ובקש להמשיך.

## סשן שכבר פתוח בטרמינל

אין שליטה ישירה בחלון Claude אינטראקטיבי זר. יש לסיים/לסגור אותו שם, לבחור אותו ברשימת השיחות השמורות ולבקש ״המשך עם ג׳ארוויס״. המערכת בודקת את רשימת הסשנים החיים ומסרבת לפתוח שוב שיחה שעדיין פעילה מחוץ לה. כישלון בבדיקת הרשימה חוסם המשך במקום להניח שאין תהליך פעיל.

מרכז עבודה → Claude מציג סשנים מנוהלים, מצב, תור, תשובה אחרונה ושדות לשליחת הוראות. לכל היותר ארבעה סשנים מנוהלים בו־זמנית ועשר הוראות ממתינות לכל סשן.

## אימות

בדיקות יחידה מכסות תור, עצירה, ביטול אישור, ביטול הרשאות, מניעת כותב כפול והסתרת הוראות מיומני אבחון. בדיקות חיות עם Claude Code מקומי מכסות פתיחה, הוראה שנייה, עצירה, המשך באותו מזהה, וסירוב לכתיבת קובץ. בדיקת המודל עוברת דרך אירועי הדיבור לאחר התמלול; היא אינה תחליף לקבלת משתמש דרך המיקרופון.
