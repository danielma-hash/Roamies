# מסכי עבודה של Jarvis

`live_panel_show` מציג מסך RTL בלשונית ״מסכים״ לצד מרכז הסשנים. קטלוג הרכיבים סגור: טקסט, טבלה עם חיפוש מקומי, גרף עמודות, טופס לתצוגה מקדימה בלבד, לוח ותרשים זרימה.

כל מחרוזת מהמודל נכנסת כטקסט. אין HTML, JavaScript, CSS, iframe, כתובות חיצוניות או פעולות שרירותיות. ה־schema מאומת גם בשירות וגם ב־WebView; מגבלות של 48KB ותקציב רכיבים משותף מונעות מסכים כבדים. הצגת נתונים אינה מאמתת את אמיתותם: `sourceNote` מציין את המקור ויש לבקש נתונים אמיתיים באמצעות הכלים המתאימים.

הכלי מחכה עד חמש שניות לאישור הצגה מהחלון, תואם מזהה וגרסה. `verified: true` מתייחס להצגת הממשק בלבד. אין הבטחת הצגה כאשר החלון לא אישר. החלפת מסך מבטלת המתנה למסך הקודם.

המסכים נשמרים בקובץ `sidekick/live-panels.json` בפרופיל המקומי, בהחלפה אטומית עם הרשאות 0600. הספרייה מכילה עד 20 מסכים, ועד חמש גרסאות אחרונות לכל מסך. בהגעה לתקרה לא נמחק מסך אוטומטית; יש לעדכן מסך קיים. קובץ פגום או לא תקין חוסם שינויים ואינו מתאפס. שחזור מחזיר מידע בלבד, ללא הפעלת כלים או פעולות.

`live_panel_list` מחזיר מטא־דאטה, `live_panel_read` קורא גרסה זמינה, `live_panel_open` פותח את הגרסה האחרונה, ו־`live_panel_update` דורש מזהה ו־`expectedRevision`. עדכון ישן נדחה בלי לדרוס שינוי חדש. המסך הנבחר נשמר ונפתח מחדש לאחר restart; מקור ותאריך עדכון מוצגים במסך. אפשר לבחור מסך גם מספריית ״מסכים שמורים״.

אין עדיין רענון נתונים ברקע או פעולות מטופס. חיפוש ושדות טופס נשמרים במעבר בין הלשוניות ובקבלת אותה גרסה שוב, אך עדיין אינם נשמרים אחרי סגירת החלון או restart. אישור פעולה בסשן מחזיר את המשתמש ללשונית הסשנים.

## אימות

- 8 בדיקות ממוקדות: schema סגור, מגבלות, קשרים בטבלה/תרשים/טופס, טקסט עוין, סינון מקומי, מניעת submit חיצוני, שימור טיוטה ואישורי הצגה.
- 172 בדיקות TypeScript עברו; 4 בדיקות Docker חיות לא הופעלו בהרצה זו.
- typecheck, build, בדיקות tool schema ו־10 בדיקות Rust עברו.
- Preview נבנה עם חתימת הפיתוח הקיימת; בדיקת codesign עברה. האפליקציה המותקנת לא הוחלפה.
- בדיקת ChatGPT אמיתית מתוך חבילת Preview: יצירה → קריאה → עדכון לאותו מזהה → עצירת התהליך → תהליך חדש → רשימה/קריאה/פתיחה. שתי הגרסאות והקובץ נשמרו ללא שינוי אחרי השחזור. בבדיקת headless לא נשלח אישור WebView והכלי דיווח `verified: false`, כנדרש.
- בדיקת ChatGPT → כלי → WebKit אינטראקטיבי עדיין ממתינה לפתיחת נעילת המק. אין לסמן זאת כבדיקה חיה שהושלמה.
