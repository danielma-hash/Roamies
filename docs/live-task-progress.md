# התקדמות משימות ב-Live UI

לרכיב query נוסף מקור `tasks`, שקורא את יומן בקשות Jarvis המקומי. לדוגמה: בקש ״תראה לי את התקדמות המשימות במסך חי״. הטבלה מציגה עד עשר בקשות אחרונות לפי מועד העדכון, מצב, מספר קריאות כלים שחזרו, צורך בבירור וזמן עדכון. סינון query פועל על טקסט הבקשה המושחר ביומן.

הנתונים מתרעננים כל שלוש שניות ללא קריאת מודל, ורק כשהחלון ממוקד, הטאב גלוי והמשתמש מאפשר נתונים חיים. השהיה מסירה את הנתונים מהטבלה. שגיאת יומן אינה מתורגמת לטבלה ריקה; היא מוצגת כ-error/stale דרך מנגנון השאילתות הקיים. לא מוצגים ארגומנטים, פלטי כלים או hashes בטבלה. ״התקבלה תשובה״ ו״קריאות שחזרו״ אינם אומרים שהמטרה אומתה.

אימות: 210 בדיקות TS עברו, 4 Docker opt-in דולגו; typecheck/build עברו. בבדיקת ChatGPT אמיתית נוצר מסך source tasks, התקבלו שני רענונים, משימה שנקטעה הופיעה כדורשת בירור ומשימה שחזרה לא הוצגה כמאומתת. הודעות focus/visibility הודמו ברמת הפרוטוקול; לאחר הסתרה התקבל paused והעדכונים פסקו. בדיקת WebKit בחלון האמיתי עדיין ממתינה לפתיחת המק; ה-PR נשאר Draft.
