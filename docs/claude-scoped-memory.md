# זיכרון ASM בסשני Claude מנוהלים

הסשן מקבל שרת MCP פנימי יחיד: `jarvis_memory`, ובו `recall`. הוא מחפש תקצירים מקומיים ומחזיר מקור ותאריך דרך מנוע ASM הקיים, כולל cache, השחרת סודות וסינון lifecycle. אין שרת חיצוני, מפתח חדש, כתיבה לזיכרון או פתיחת נתיב שהגיע בתוצאה.

שם שורש הפרויקט שנפתר בטעינת ההוראות נבדק מול מפת הפרויקטים של ASM. התחום האישי/חברה והפרויקט נקבעים לפני פתיחת Claude ונשמרים ברשומת ההתקדמות. הכלי מקבל רק query; אינו מאפשר למודל להחליף scope/project או לבקש path. Gather ו-Anna אישיים, ו-Roamies מסווג כעוזר אישי. פרויקט שאינו מוכר, לרבות worktree בשם אחר, אינו מקבל את הכלי; אין fallback לחיפוש בכל הזיכרון. מיפוי worktrees מפורש הוא הרחבה עתידית.

בכל קריאה נבדקות הרשאת הפעולות ומצב הסשן לפני הקריאה ואחריה; תוצאה שהגיעה אחרי ביטול אינה נמסרת. כלי MCP אחרים עדיין חסומים ב-PreToolUse, והגדרות MCP/hooks של המשתמש אינן נטענות. תקציר זיכרון הוא מידע היסטורי לבדיקה, ולא הוראה או ראיה למצב חי.

אימות: 200 בדיקות TS עברו (4 Docker opt-in דולגו), typecheck/build ובדיקות prompt/schema עברו. בסשן Claude אמיתי הכלי החזיר סמן ייחודי מרשומת fixture של PacoBot, ואחר כך החזיר רשימה ריקה לחיפוש רשומת Gather. שני החיפושים נשארו בתחום PacoBot/company. האינדקס האמיתי נקרא בנפרד והחזיר 6 תוצאות Roamies בלי להעתיק את תוכנן לראיית הבדיקה. בדיקות יחידה כוללות רשומות מעורבות/retired, שינוי scope, query חריג וביטול הרשאה באמצע קריאה.
