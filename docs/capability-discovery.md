# קטלוג יכולות וטעינת כלים

`discover_capabilities` מציג קבוצות יכולות, דרישות ואת שמות הכלים המוגדרים בפועל.
קריאה עם `family` טוענת את הקבוצה: סשנים, ASM, רשת, דפדפן, מחשב, קבצים,
התחייבויות או תמונות. כלי התצוגה הבסיסיים זמינים מתחילת השיחה.

במסלול ChatGPT/API המודל מתחיל עם כלי הליבה והגילוי. רשימת הכלים החיה מורחבת
באותו Agent; קריאה לכלי רשום בשם מדויק יכולה גם לפתור את הכלי ולטעון את קבוצתו.
ב־API שתומך ב־deferred tools נשלח גם קטלוג יציב לפי החוזה של gg-agent.
במסלול Claude Code נשמרים כל הכלים ב־MCP, משום שהגשר הנוכחי אינו מעדכן קטלוג
דינמי בזמן ריצה. כלי הגילוי עדיין זמין שם, אך אין טענת צמצום schemas במסלול הזה.

`configured` אינו בדיקת בריאות, ו־`actionsSettingEnabled` אינו הרשאה לפעולה.
הגילוי אינו מריץ את הכלים, אינו משנה הגדרות ואינו עוקף את ה־executors הקיימים.
המדיניות והאישורים נבדקים בזמן הפעולה המקורית. קבוצות שאין להן adapter מותקן
מוחזרות עם `configured: false`. אין חיבור ליומן או לדוא״ל מעצם קיום הקטלוג.

אימות ב־14/11/2026: שש בדיקות קטלוג והרשאות; 150 בדיקות TypeScript עברו;
בדיקות prompt/schema, typecheck ו־build; Preview חתום ובדיקה אמיתית
ChatGPT→discover_capabilities(browser)→browser_open→browser_read→browser_close.
