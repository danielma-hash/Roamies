# משימות Browser Use לקריאת אתרים

ארבע פקודות: `browser_open`, `browser_read`, `browser_jobs`, `browser_close`.
הן נרשמות כאשר נמצאים Docker CLI ו־socket מקומי. נדרשות התמונות המקומיות המתועדות
ב־[בדיקת runtime](browser-runtime-validation.md) וב־[גבול הרשת](browser-egress.md).
אין הורדה אוטומטית של תמונות או שימוש ב־Docker context מרוחק.

`fetch_url` נשאר הבחירה הראשונה. Browser Use נועד לדפים הדורשים JavaScript.
כל משימה מקבלת רשת פנימית, proxy ומכולת Chromium משלה. אין גישה לטאבים,
לפרופיל, לקבצים או להתחברויות של המשתמש. אין כלי להרצת קוד שרירותי, לחיצה או מילוי טופס בשלב זה.

מגבלות: שתי משימות, חמש דקות ועשרים קריאות למשימה. הטקסט הנקרא מהדף מוגבל
ל־80,000 תווים; כל תשובה מכילה עד 5,000 תווים, עד עשרה קישורים וטבלה אחת קטנה.
ניתן לחפש קטע או להמשיך ב־`nextOffset`. כל תוצאה כוללת מקור, זמן תצפית ותוקף.
תוכן האתר מוגדר מידע בלתי מהימן ואינו מעניק הרשאות.

בסגירה נבדקים labels של בעלות ומזהה משימה לפני מחיקת משאבים לפי ID.
ביטול בזמן יצירת מכולה ממתין לסיום פקודת Docker לפני הניקוי. כשל ניקוי מוצג ככשל,
ולא כהצלחה. יציאת האפליקציה מנסה לנקות; יציאה כפויה מסתמכת על מגבלת חמש הדקות
בתהליכים עצמם. רשתות ריקות שנותרו אחרי קריסה, ושגילן מעל עשר דקות, מנוקות בפתיחת
המשימה הראשונה של אותו פרופיל. אין חידוש אוטומטי של משימות אחרי restart.
אם Docker עצמו אינו מגיב או נעצר, אי אפשר להבטיח ניקוי עד שהוא חוזר.

אימות:

```sh
npx vitest run test/browser-task.test.ts
ROAMIES_BROWSER_LIVE=1 npx vitest run test/browser-task.live.test.ts
```

הבדיקה החיה עוברת דרך אותם ארבעה adapters, קוראת HTTPS ציבורי, מחפשת קטע,
סוגרת ומוודאת שלא נשארו מכולות או רשתות של הבדיקה. בדיקות היחידה מכסות ביטול
בזמן יצירה, בעלות, מגבלות, חוזה פלט למודל ושגיאת קריאה. אין כאן טענה לחיסכון
בטוקנים, לתמיכה באתר מחובר או לאימות פעולה בטופס.

אימות נוסף ב־14/11/2026: sidecar חתום מתוך `Roamies Preview.app` עם התחברות
ChatGPT קיימת ופרופיל בדיקה נפרד הפעיל `browser_open` → `browser_read` →
`browser_close` והחזיר תשובה בעברית עם מקור. שלוש הקריאות הצליחו והסגירה אישרה
`closed: true`. האפליקציה המותקנת וההרשאות שלה לא שונו.
