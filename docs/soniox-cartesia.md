# Soniox ו־Cartesia במק

גרסה מותאמת של Roamies: זיהוי דיבור ב־Soniox `stt-rt-v6` ודיבור ב־Cartesia `sonic-3.6` בעברית.
ברירת המחדל היא Oren. בהגדרות הקול אפשר לבחור חמישה קולות גבריים וחמישה נשיים ולהאזין לדוגמה.
ממשק המשתמש, מדריך ההגדרה והתפריטים מותאמים לעברית ול־RTL. קוד, מפתחות, כתובות וקיצורי מקשים נשארים LTR.
JARVIS מקבל הנחיות לעברית ישראלית טבעית ולפנייה לדניאל בזכר. בועות הדיבור מציירות שורות עבריות בשלמותן,
כדי לשמר את סדר האותיות ואת השילוב עם אנגלית ומספרים. שמות קולות נבדקו מול קטלוג Cartesia.
המפתחות נשמרים ב־macOS Keychain באמצעות אותו מנגנון מוצפן של האפליקציה, בנפרד: `soniox` ו־`cartesia`.
אין צורך במפתח Fish Audio או בהרשאת זיהוי הדיבור של Apple. עדיין נדרשת הרשאת מיקרופון.

ההאזנה פועלת בהחזקה או בלחיצה על קיצור הדיבור. Wake word אינו פעיל בגרסה הזו; לא נשלח אודיו רציף מהחדר לענן.
העדכון האוטומטי מהפרויקט המקורי חסום במק כדי שלא יחליף את המנועים המותאמים.
ההתאמה של Soniox מתייחסת למק בלבד; מנגנון ההאזנה המקורי ב־Windows וב־Linux נשאר כפי שהיה.

## בנייה ובדיקה

```sh
cd showcase/tauri/sidecar
npm ci
npm test
cd ..
./build.sh dev
./sidecar/node_modules/.bin/tauri build --debug --bundles app --config '{"bundle":{"createUpdaterArtifacts":false}}'
```

האפליקציה נמצאת ב־`src-tauri/target/debug/bundle/macos/Roamies.app`.
מנועי הקול ב־TypeScript strict. עוזר Swift מטפל במיקרופון ומעביר PCM בתעלה מקומית למנוע Soniox.
Cartesia מזרים PCM ישירות למסלול השמעת האודיו הקיים. עצירה מבטלת בקשות ומונעת אודיו מתור קודם.

מקורות API: [Soniox WebSocket](https://docs.soniox.com/api-reference/stt/websocket-api),
[Cartesia TTS](https://docs.cartesia.ai/api-reference/tts/bytes). מפתח Soniox נשלח בכותרת Authorization,
ומפתח Cartesia נשלח רק ל־Cartesia עם גרסת API `2026-08-14`.

בדיקות אוטומטיות מכסות PCM, סדר משפטים, עצירה, שגיאות, partial/final של Soniox, סיום הזרם וקטלוג 10 הקולות.
בוצעה גם בדיקת Cartesia→Soniox חיה בעברית; בדיקה זו אינה תחליף לשיחה של המשתמש במיקרופון האמיתי.

## הגייה וטקסט מעורב

כל הקראה עוברת דרך `SpeechPreparer`, בגבול היציאה לקול. הטקסט המוצג והזיכרון אינם נכתבים מחדש.
רצפי אנגלית נשמרים בכתיב המקורי ונשלחים עם `language: en`; עברית נשלחת עם `language: he`.
הקול והפורמט זהים בכל המקטעים, וה־PCM מושמע בסדר המקורי. זה מיישם את
[הנחיית Cartesia לשלוח שפה אחת בכל בקשה](https://docs.cartesia.ai/build-with-cartesia/capability-guides/multilingual-voices#switching-languages-mid-conversation).
מעברים רבים בין שפות מוסיפים בקשות ומשנים את קצב המשפט; אין החלפה לקול אנגלי אחר.

לקחי Vocaly שהוחלו כאן:

- ניקוי Markdown, כיווניות ותגיות ביצוע לפני הדיבור; תוכן בסוגריים ותוויות קישורים נשמרים.
- קיצורים עבריים נבחרים מתרחבים בגבולות Unicode, כולל אותיות שימוש; אין החלפת חלקים בתוך מילים.
- טלפונים, מספרי כוכבית וקודים מפורשים נקראים ספרה אחר ספרה, כולל אפסים בתחילה.
- סכומים עשרוניים בשקלים מפורקים לשקלים ואגורות. שעות נשמרות כיחידה וטווח נכתב עם ״עד״.
- ניקוד קיים נשמר. הכלל הממוקד ל״שמחה ש…״ בתחילת פסוקית משתמש ב־`שְׂמֵחָה`;
  שם העצם ״רגעים של שמחה״ אינו משתנה.
- אותיות שימוש נבחרות לפני שם באנגלית מצטרפות למקטע האנגלי עם הנחיית צליל של Cartesia:
  `ב־ChatGPT` ו־`ובGitHub`, במקום בקשה נפרדת שמקריאה את האות כמילה.
- שלוש נקודות וכותרות באנגלית כגון `Dr.` אינן מנתקות את הקשר ההגייה באמצע משפט.
- JARVIS מקבל הנחיה להשאיר שמות באנגלית בכתיבם המקורי ולא להמציא תעתיק או ניקוד לשמות.

לא הועתקו מילוני ההגייה של ElevenLabs או Soniox TTS: תיקון שמועיל לקול מסוים עלול לפגוע בקול אחר.
מספרים רגילים, תאריכים ויחידות נשארים בהקשר עבור מנרמל Cartesia; אין ניחוש של המין הדקדוקי לכל מספר.
בדיקות כוללות מקרי נגד של ימי השבוע, מילים חופפות, שם עצם מול תואר, ו־idempotence.
בדיקת תמלול חוזר מודדת מובנות בלבד; זיהוי הצלילים ובדיקה באוזן עדיין נדרשים להכרעה בהטעמה ובתנועות.
