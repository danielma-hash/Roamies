# פעולות Browser Use על רכיבים מזוהים

`browser_controls` קורא עד 30 רכיבים סמנטיים גלויים מתוך משימת דפדפן קיימת.
`browser_act` ממלא שדה או לוחץ על כפתור/קישור נתמך. המודל מבקש את הפעולה בכלי;
הכלי עצמו מציג אישור מדויק עם המקור, שם הרכיב והטקסט למילוי.
אין צורך באישור נוסף בצ׳אט לפני פתיחת חלון האישור.

כל ref הוא UUID מקומי הקשור למשימה, URL, frame, loader, backend node ומאפייני
הרכיב שנצפה. הוא תקף לדקה, וכל פעולה צורכת את כל הפניות המשימה. לאחר האישור
נבדקים שוב ההרשאה, המסמך, ה־origin והמאפיינים. שינוי ב־SPA, החלפת רכיב או ניווט
מונעים שימוש בהפניה הישנה. יש נעילה בזמן המתנה לאישור ובזמן ביצוע.

הגישה משתמשת ב־Browser Use וב־CDP בתוך המכולה הקיימת. הקוד המורץ קבוע;
URL, טקסט ו־IDs מועברים כנתוני JSON. פעולת DOM מתבצעת ב־isolated world, עם
בדיקת מקור משותף לדף הראשי. נתמכים הדף הראשי ו־iframes נגישים מאותו origin,
כולל srcdoc יורש origin. מסגרות זרות/מוגבלות אינן מקבלות הרשאת גישה אוניברסלית.
שדות סיסמה, קובץ, שדות מוסתרים, מושבתים או לקריאה בלבד אינם ניתנים לפעולה.

מילוי מאומת רק ביחס לערך השדה אחרי אירועי input/change. לחיצה היא מסירה סמנטית
באמצעות DOM, ולא הוכחה שהמטרה הושלמה. תשובת הכלי כוללת קריאה נוספת של הדף;
המודל צריך לבדוק אותה מול הבקשה. אתר הדורש אירוע pointer מהימן עשוי לסרב לפעולה
סמנטית. אין fallback אוטומטי למקלדת/עכבר ואין ניסיון נוסף אחרי תוצאה לא ידועה.
כשל בתקשורת בזמן פעולה סוגר את משימת הדפדפן ככל שניתן ומחזיר unknown.

קריאות רכיבים ופעולות נכללות בתקציב עשרים הפעולות ובמגבלת חמש הדקות למשימה.
אין פרופיל מחובר, cookie של המשתמש, העלאת קובץ או גישה לטאבים שלו.

אימות: שבע בדיקות שירות, בדיקות מדיניות, ובדיקת Chromium אמיתית עם HTML של
fixture שהוזרק רק לטאב בדיקה מבודד. נבדקו עברית, מילוי וקריאת ערך חוזרת,
לחיצה ושינוי טקסט מקומי, iframe, מסגרת מוגבלת, סיסמה/קובץ/disabled, שינוי שם
ב־SPA, החלפת node וניווט. הטופס לא שולח מידע לאתר חיצוני.

```sh
npx vitest run test/browser-controls.test.ts
ROAMIES_BROWSER_LIVE=1 npx vitest run test/browser-controls.live.test.ts
```
