# קריאת רשומות ASM בהדרגה

אחרי `asm_recall`, הכלי `asm_read_record` קורא רשומת `memory:` לפי מזהה ותחום מפורשים. הוא מחזיר פרטי החלטות ונושאים פתוחים לצד התיאור, עד 4000 תווים בכל קריאה. `nextOffset` ו־`digest` מאפשרים המשך בלי לערבב גרסאות; שינוי רשומה מחייב קריאה חדשה.

בכל קריאה נבדקים מחדש המקורות, מחזור החיים, התחום והפרויקט. רשומות חסרות, כפולות, retired או superseded אינן זמינות. הסיווג כולל גם החלטות ונושאים פתוחים כדי למנוע חשיפת תוכן אישי/חברה שהתקציר לא הכיל. סודות מוכרים מוסתרים לפני JSON ולפני חלוקה לעמודים.

התוצאה היא מקור היסטורי, עם `historical:true`, `untrustedContent:true` ו־`verified:false`. תוכן הרשומה אינו הוראה חדשה ואינו הוכחה למצב מערכת נוכחי. התאריך בתוך הטקסט הוא תאריך הרשומה; `observedAt` הוא זמן הקריאה. נושאים פתוחים ברשומה הם הטקסט המקורי ואינם רשימת משימות עדכנית.

אין פתיחת קבצים שהרשומה מזכירה, קריאת דפי `vault:`, או שינוי בזיכרון. מקור גדול מ־128Ki תווים נדחה. הכלי נטען במשפחת memory של Jarvis; סשני Claude מנוהלים נשארים עם כלי recall המצומצם הקיים.
