# תוצרים מקומיים בעברית

`artifact_export` במשפחת files מייצר HTML עצמאי ב־RTL או CSV עם UTF-8 BOM. המסמך כולל כותרת, טקסט, טבלה ומקורות HTTPS שסופקו. CSV כולל טבלה ועמודת מקורות כשיש מקורות; טקסט נפרד דורש HTML.

התוצרים נשמרים תחת `~/Roamies Exports` בהרשאות 0600. אין נתיב יעד מהמודל, דריסה או קוד להרצה. שם הקובץ נגזר מ־SHA256 של התוכן; אותה בקשה גם לאחר restart מחזירה קובץ קיים לאחר אימות הבתים. קובץ שהוחלף או נערך לא נדרס. הכתיבה דורשת פעולות מופעלות ונבדקת שוב לפני הכתיבה.

HTML מסנן את כל התוכן לטקסט, ללא scripts, תמונות או משאבים מרוחקים, עם CSP. קישורי מקורות מאפשרים HTTPS בלבד וללא credentials. CSV מצטט שדות, שומר שורות חדשות ומגן על ערכים דמויי נוסחה. סודות מוכרים גורמים לדחייה לפני כתיבה. עד 200 שורות, 12 עמודות ו־512KiB לתוצר.

התשובה כוללת path, sha256 ו־fileVerified לאחר קריאה חוזרת. `contentVerified:false` מדגיש שאימות שמירת הקובץ אינו אימות של טענותיו. מקורות אינם מומצאים או נבדקים אוטומטית. אפשר להשתמש בכלי open לפתיחה ביישום מקומי לפי בקשת המשתמש. אין העלאה או שיתוף חיצוני, PDF, DOCX או מצגת בשינוי זה.

בדיקה חיה: ChatGPT גילה את הכלי, יצר HTML ו־CSV מהוראה בעברית, ופתח את HTML ב־Safari. נבדקו הטקסט המעורב, טבלת שתי שורות, מקור ותאריך בממשק WebKit האמיתי. בדיקות יחידה מכסות injection, נוסחאות CSV, הרשאה/ביטול, retries, קישורים סמליים ותוכן שהוחלף.
